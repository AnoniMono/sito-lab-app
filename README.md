# Sito Lab App

Static site, no build step. Upload this folder as-is to any static host
(GitHub Pages, Netlify, Vercel, Cloudflare Pages); `index.html` is the entry page.

- `index.html` landing page
- `team/` one page per person
- `studio/` the embeddable Veyra Studio demo
- `media/` videos, images, team photos (`media/team/martina.jpg`, `filippo.jpg`)

Preview locally: `python -m http.server 5310` in this folder, then open http://localhost:5310/
